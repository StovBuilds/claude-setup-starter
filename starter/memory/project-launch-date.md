The shop launches on 1 March. From 22 February only bug fixes go in.

**Why:** the launch is tied to a newsletter that goes out that morning and can't move.

**How to apply:** if a new feature is suggested after 22 February, park it on the desk for after
launch instead of building it. Dates are written in full, never "next week", so this note still
makes sense later.
